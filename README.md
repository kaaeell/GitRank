# GitRank

GitRank is a project I'm building to analyze GitHub profiles and eventually give them a score based on things like projects, activity, languages, and overall profile quality.

I'm building it mainly to learn how APIs work, how to work with real-world data, and how to turn that data into something useful.

Right now, GitRank is still in the early stages. The first version connects to the GitHub REST API and retrieves basic information about a GitHub user.

## What it can do right now

* Enter a GitHub username
* Get the user's profile from GitHub
* Show their:

  * Username
  * Name
  * Followers
  * Following
  * Public repositories
* Handle usernames that don't exist
* Handle empty input
